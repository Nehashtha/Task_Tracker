# Task Manager

A simple command-line Task Manager application built with Python and Object-Oriented Programming (OOP).

## Features

- Add a new task
- View all tasks
- Update a task
- Filter tasks by ID
- Filter tasks by category
- Search tasks by word
- Remove a task
- Different validation like priority, due date, category, input
- Save and load tasks using JSON
- Unit testing with pytest

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- Pytest
